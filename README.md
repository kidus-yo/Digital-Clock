# 🕒 Digital Clock

A simple digital clock application built with **Python** and **PyQt5**. This project displays the current time in a graphical user interface and updates automatically every second.

The main purpose of this project is to practice building desktop GUI applications using PyQt5 and understand how event-driven applications work.

---

## ✨ Features

* Displays the current time
* Updates automatically every second
* Graphical User Interface (GUI)
* Clean and simple interface
* Real-time clock functionality

---

## 🛠️ Technologies Used

* Python 3
* PyQt5
* `datetime`
* `QTimer`

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kidus-yo/digital-clock.git
```

### 2. Navigate to the project directory

```bash
cd digital-clock
```

### 3. Install the required dependency

```bash
pip install PyQt5
```

### 4. Run the application

```bash
python main.py
```
